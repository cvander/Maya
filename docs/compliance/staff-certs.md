## Requirements

- **RBS Certification**: Mandatory for all servers/bartenders in California since July 1, 2024 (AB 1221).
- **Renewal**: Every 3 years. $3 per certification.
- **New hires**: Must obtain RBS within 60 days of hire.
- **Provider**: ABC-approved provider list at abc.ca.gov.

## Tracking Rules

- Flag renewals 30 days before expiry.
- A server without current RBS cannot serve alcohol. Period.
- Keep copies of certificates on file at the bar.
- Update this file whenever someone is hired, leaves, or renews.
