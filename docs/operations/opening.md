# Opening Checklist

Run through this before the doors open. Every shift, no exceptions.

---

## Behind the Bar

- [ ] Ice bins filled (main well + backup)
- [ ] Garnish prep: lemons (wheels + twists), limes (wedges), oranges (peels)
- [ ] Olives stocked, brine fresh
- [ ] Simple syrup -- check level, make fresh if low or older than 1 week
- [ ] Vermouth -- check Opened date in spirits inventory. Past 5 days, pour out and open new
- [ ] Juice: OJ fresh squeezed or received, cranberry stocked
- [ ] Glassware polished and staged (rocks, coupe, pint, wine)
- [ ] Speed rail stocked and in order
- [ ] Draft lines -- pull a short pour from each tap, check for off flavors
- [ ] Bottle count -- eyeball the well. Anything below 1/4 gets a backup pulled

## Front of House

- [ ] Tables wiped, chairs set
- [ ] Floor swept/mopped
- [ ] Bathrooms checked (soap, paper, clean)
- [ ] Music on, volume appropriate for empty room (adjust as it fills)
- [ ] Lighting set (not full bright, not cave dark)
- [ ] Menu boards updated if anything changed or is 86'd
- [ ] A/C or heat set for the weather

## Cash & Systems

- [ ] POS powered on, test transaction
- [ ] Cash drawer counted, starting bank verified ($______)
- [ ] Card reader tested
- [ ] Tabs from last night -- any still open? Close or note for follow-up

## Compliance

- [ ] Liquor license visible behind bar
- [ ] Health permit visible near entrance
- [ ] Fire exit clear, not blocked
- [ ] ID check supplies ready (flashlight for dim lighting)
