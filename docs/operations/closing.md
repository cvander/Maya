# Closing Checklist

Last call is at 1:30 AM. Doors locked at 2:00 AM. This gets done before anyone leaves.

---

## Cash Out

- [ ] Close all open tabs -- no exceptions, no "they'll come back tomorrow"
- [ ] Run POS end-of-day report
- [ ] Count cash drawer
- [ ] Record: starting bank, cash sales, credit sales, tips, variance
- [ ] Drop cash in safe (keep starting bank for tomorrow)
- [ ] Note any discrepancies -- don't guess, write it down

## Bar Breakdown

- [ ] Wash all glassware, run through sanitizer
- [ ] Wipe down bar top, speed rail, back bar
- [ ] Empty ice wells, wipe and leave to dry
- [ ] Cap or cork all open bottles
- [ ] Refrigerate vermouth, wine, and anything perishable
- [ ] Restock beer cooler from back stock (so tomorrow's opener isn't scrambling)
- [ ] Check draft system -- turn off CO2 if that's the house rule, or leave on
- [ ] Dump garnish trays, wash containers
- [ ] Wipe down soda gun and beer taps

## Front of House

- [ ] Chairs up on tables (or tucked in, house preference)
- [ ] Floor swept and mopped
- [ ] Bathrooms: final check, lights off
- [ ] Trash out -- all bins, bar and bathrooms
- [ ] Recycling sorted (glass separate)

## Security

- [ ] Back door locked
- [ ] Windows secured
- [ ] Lights: leave bar lights on low or off per house rule
- [ ] Alarm set (if applicable)
- [ ] Front door locked, key accounted for

## Shift Notes

Write down anything the next shift needs to know:

```
Date: ____-__-__
Bartender: ________________

What happened tonight:


What's 86'd:


What needs attention tomorrow:


Anything weird:

```

---

**Time target**: 30-45 minutes after last guest leaves.
**Who**: Closing bartender. Nobody leaves until this is done.
**The close-out skill (when built) will handle the cash math. Until then, pen and paper works.**
