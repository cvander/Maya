# Support

## Getting Help

- **Questions, ideas, and general feedback**: [Open an issue](https://github.com/cvander/Maya/issues/new)
- **Bug reports**: Use the [bug report template](https://github.com/cvander/Maya/issues/new?template=bug_report.yml)
- **Feature requests**: Use the [feature request template](https://github.com/cvander/Maya/issues/new?template=feature_request.yml)

## Before Asking

1. Check existing [issues](https://github.com/cvander/Maya/issues) - someone may have asked already
2. Read [AGENTS.md](AGENTS.md) for operational rules and hard stops
3. Read [skills/README.md](skills/README.md) for skill documentation

## This is a Research Project

Maya is an experiment in bringing AI to bar management. Things will break. Features are added as they're tested in a real bar. Patience appreciated.
